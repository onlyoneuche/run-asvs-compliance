- Review date:

## Summary

Lead with **Change-scoped ASVS result: meets reviewed controls / does not meet reviewed controls / undetermined** (or **Baseline result** when no change was identified). Name the applicable controls and change range. Summarize new risks, existing findings, checks completed, and key unknowns. State the count of controls in each status and the areas not reviewed. Do not use a positive result when any applicable reviewed control is partial or still needs a material runtime check.

## Control evidence

| Control | Status | Evidence | What remains to verify | Action |
| --- | --- | --- | --- | --- |
| Checklist ID | Verified by available evidence / Partial / Gap / Needs runtime check / Not applicable | `path:line-line`, test result, or documented configuration | Specific unknown | Specific next step |

## Priority findings

For each finding: impact, affected path, evidence, uncertainty, fix, and a test that could show the fix works. Keep facts and inferences separate.

## Verification plan

List safe local or staging tests in priority order. Name any required access, deployment configuration, or owner confirmation.
